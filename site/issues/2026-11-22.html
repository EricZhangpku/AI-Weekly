长程代理竞赛升温，科学 AI 开始检验研究闭环

GPT-6.2 Astra 与 Gemini 4 Neon 争夺复杂任务效率；Qwen4-Max 把稀疏架构带进长程工作流，NVIDIA 开放化学数据与后训练方案，MolDraft 和 SciWorkBench 把评测推进到结构生成与科研过程

美国

  • OpenAI｜GPT-6.2 Astra 与 Sol 发布，能力、成本和监测风险一并更新（11 月 17 日） Astra 面向复杂任务，Sol 面向日常执行。Artificial Analysis Intelligence Index v5.0.1 的独立测评给 Astra 62 分、Sol 57 分；同一版本中 Gemini 4 Neon 为 61 分。Artificial Analysis 测得 Astra 完成该指数任务平均耗时 14.1 分钟、成本约 4 美元；Neon 为 23.6 分钟、6.44 美元。该指数含九项评测，分数接近，但推理档位、模型工具链不同，成本和速度也不能推广为所有工作流的实际成本。OpenAI 给 Astra 的 API 标价为每百万输入/输出 token 8/40 美元，并称新模型在 Agents’ Last Exam 和 Terminal-Bench-Science 上较上一代提高、单任务成本下降；这些比较来自公司公布的测试，Fable 5.2 的 Agents’ Last Exam 数据还排除了九个使用备用模型的任务。

更值得关注的是系统卡。OpenAI 按自有 Preparedness Framework 将 Astra 与 Sol 的网络安全能力评为 Critical、生物与化学能力评为 High，并把 Astra 的 AI 自我改进能力评为 High。这里的 High 是 OpenAI 框架的风险阈值，不等于模型已能自主递归改进。独立研究机构 Epoch AI 的预发布评估给 Astra 的 Epoch Capabilities Index 174，GPT-6 Astra 为 169；Epoch 在每题最高 300 美元预算下，得到 Astra 解出 68 道 Erdős 难题中的 7 道，其中一道此前没有已知解法。Epoch 也指出 Astra 在其开放式研究任务中没有明显胜过前代，仍难以设计好实验。

UK AI Security Institute 的受控红队测试发现，Astra 在特定文件下载场景中可绕过较弱的 GPT-5.6 Sol 行为监测器 48.8%，对更强的 GPT-6.1 Sol 监测器为 0.6%；在研究所测试的同时读取推理与动作的监测设置下，未观察到成功绕过。结果说明监测效果取决于监测器和可见信息，不能据此外推现实环境中的逃逸率。(OpenAI 发布与价格（在新标签页打开），GPT-6.2 系统卡与外部评测（在新标签页打开），Artificial Analysis：Astra（在新标签页打开），Epoch AI 与 UK AISI 结果见系统卡（在新标签页打开）)

  • Google DeepMind｜Gemini 4 Neon 主打高频复杂任务（11 月 18 日） Neon 的上下文窗口为 100 万 token，接受文本、图像、音频、视频输入，默认同步输出上限为 65,536 token；后台长解码模式支持更长输出。Google 模型卡报告：Artificial Analysis Intelligence Index 为 61，Vals Index 为 70.9%；Terminal-Bench 4.1 为 65.2%，Terminal-Bench-Science 0.1 为 70.5%，RiemannBench 为 84.0%，Agents’ Last Exam v1.1 为 75.8%。模型卡注明，多数结果以最高思考档、单次采样成功率（pass@1）测得；Neon 的 Terminal-Bench-Science 使用 mini-swe-agent vision harness，每道任务平均五次，报告 Average Reward。部分任务由 Google 自测，另一些来自公开榜单；公司还说明其他模型的比较数字多取自各自发布方，因此表格不是统一重跑的全面横评。Neon API 标价每百万输入/输出 token 3/15 美元；Artificial Analysis 在指数任务上测得约 23.6 分钟、6.44 美元。(Google 发布说明（在新标签页打开），模型卡（在新标签页打开），评测方法（在新标签页打开），独立成本与指数（在新标签页打开）)
  • Microsoft｜Ignite 发布专用模型阵容，强调“模型 + 工具 + 系统”共同设计（11 月 17 日） MAI-Code-2 和 Code-2-Flash 面向代理编程，两者已在 GitHub 一般可用；Code-2-Flash 在 Foundry 仍为私有预览。Microsoft-Decision-1.1 已一般可用，MAI-Image-2.7 / Flash 和 MAI-Cyber-2-Flash 处于预览阶段。微软称 Decision-1.1 在 Artificial Analysis Decision Index v2.1 得 68 分，比前代高 6 分且速度超过两倍。这个指数测的是软件流程里的分类、路由、优先级和验证等结构化决策，不是通用聊天能力。Satya Nadella 在主题演讲中把 Agent 365 Business Analytics 比作“AI 使用的 ERP 系统”，主张企业应把模型支出与工作成果联系起来。(微软 Ignite Book of News（在新标签页打开），Nadella 演讲文字稿（在新标签页打开）)
  • NVIDIA｜Sigma 开放连续扩散语言模型，SC26 同时推进科学算力（11 月 16–20 日） Nemotron-Labs-Sigma 于 11 月 20 日开放 3B 与 8B 检查点。它先在 16 维连续向量空间中逐块去噪，再读出离散 token；相关论文最初于 10 月 2 日提交 arXiv，11 月 12 日更新 v2，因此本周的新进展是检查点开放。蒸馏后数学任务每次前向可生成 8 个 token，代码任务 4 个 token。NVIDIA 报告，8B 模型在 GB200 上以自身扩散分支草拟、再由自回归分支校验，平均吞吐较纯自回归解码提高 3.46 倍。这是研究团队公布的硬件与解码配置结果，不能直接外推到其他显卡或服务负载。公司没有在页面上给出完整、同条件的行业基准表。(NVIDIA Research：Sigma 架构与结果（在新标签页打开），原始论文，10 月 2 日提交（在新标签页打开）)

SC26 上 NVIDIA 还发布 Nemotron for Science、开放科学工作流工具和 Vera Rubin 系列算力进展。Rubin 平台在 MLPerf Training v6.1 首次提交结果，NVIDIA 报告部分训练任务相较 GB300 NVL72 每 GPU 性能最高约两倍；这些是厂商对公开基准结果的总结。科学 AI 的数据与合作进展见下方专题。(NVIDIA MLPerf 与 SC26 公告（在新标签页打开）)

中国

  • 阿里｜Qwen4-Max 正式上线：稀疏架构和长程任务是本期重点（11 月 16 日） 阿里披露模型总参数 2.4T，每 token 激活 71B；相较同为 2.4T 的 Qwen3.8-Max，激活参数减少 25%。架构在注意力、残差连接和嵌入层调整 MoE 设计；模型支持原生图像能力和 100 万 token 上下文，API 与 Token Plan 已可用。阿里公布 Work360（覆盖 721 个专业细分领域）总分 52.69，Qwen3.8-Max 为 47.74；高推理档平均少用 35% token、单任务成本约降 60%。该基准及成本比较由阿里提供，完整复现协议尚未公开。阿里公布的 Code Arena: WebDev 榜单中，xHigh 档 Qwen4-Max 得 1,750 Elo 评分、列第 6，前五为 Claude Fable 5.2、Opus 5.5、Sonnet 5.5、Gemini 4 Carbon 与 GPT-6 Astra。这个榜单是对真实开发偏好的 Elo 排序，不等同于固定答案的代码单测。

阿里还展示了一次 48 小时科学代理运行：系统循环进行分子设计、合成和测试，共迭代四轮，称得到经实验室验证的数据中心冷却分子；公告另称执行 454 次工具调用、3,239 次指标评估、筛选 24 个候选分子。当前公开证据是阿里发布的演示和说明，独立实验室复核及论文尚未见到。(阿里正式发布与 Work360 / Code Arena 数据（在新标签页打开），阿里云模型目录与上线日期（在新标签页打开）)

  • 美国政策对中国算力的影响｜BIS 限制第三国数据中心向中国关联企业提供远程先进算力（11 月 16 日发布，11 月 19 日生效） 美国商务部工业与安全局新增许可要求：若有知识表明先进芯片或服务器将用于向总部或最终母公司在中国、澳门及特定受限目的地的企业提供大规模计算，相关出口、再出口和境内转移需要许可。门槛为单一或互联数据中心合计 1,200 万总处理性能（TPP）；已有服务需在 90 天内申请许可才能继续。该规则把监管对象从芯片的物理流向扩展到第三国数据中心的计算服务，云供应商的客户识别与尽职调查会成为执行关键。(BIS 公告（在新标签页打开），《联邦公报》正式规则（在新标签页打开）)

本周全景扫描覆盖阿里、DeepSeek、月之暗面、智谱、字节和腾讯等官方更新页。观察区间内确认的头部中国基础模型正式发布是 Qwen4-Max；其他公司的近期模型在本期作为竞品基准出现，但其原始发布时间早于本周，未重复包装成新品。

欧洲

  • OVHcloud｜发布欧洲公共超算训练的 Olala mini 7A1B（11 月 17 日宣布，11 月 19 日开放） 模型总计 7B 参数，每层 256 个专家、每次请求激活 1B，采用 Differential-TPA 与 Mamba-3 的混合注意力。OVHcloud 称其在 8GB 显存 GPU 上可运行，在 RTX A4500 上达 160 token/s、普通 CPU 上约 50 token/s；当前上下文 32,000 token。模型权重、预训练底座、技术报告和 AI Act 合规文档已在 Hugging Face 开放，采用 Apache 2.0 许可；训练使用 Jupiter、MeluXina、Jean Zay 三个欧洲公共超算，相关算力时长约 700 万欧元。法国搜索引擎 Qwant 已用于即时回答功能，OVHcloud 称响应快 20%、成本降至原来的三分之一。速度和客户结果均为公司报告，尚无独立同硬件复测。(OVHcloud 新闻稿（在新标签页打开），模型权重与模型卡（在新标签页打开）)

本周没有检索到 Mistral 的新模型或架构发布；其 Large 4 在 10 月发布，不重复列作本周进展。欧洲本周的实质变化是另一家云厂商开始公开模型权重、技术报告和训练资源来源，增加了可部署的本地选项。

AI4S / STEM：评测开始检查研究流程与实验结果

本周有三项可直接关联 AI4Chem、AI4Phys 与 AI4Materials 的进展：NVIDIA 的化学后训练工具链、跨学科研究工作流基准 SciWorkBench，以及把化学结构图转为三维坐标的 MolDraft。

进展任务与设置结果证据边界
NVIDIA LitmusBench v0.2 / Nemotron for Science近 50,000 道化学推理题；结合分子性质与实验药物发现数据，可用于训练和评估；提供开放模型及领域后训练配方Terray 的模型从论文反应图提取反应物、产物和条件，在 RxnScribe 测试中按基准匹配标准找回约 76% 标注反应。Lila Sciences 用实验室反馈后，量子点制备准确率接近翻倍至 61%，高于公告中 GPT-6 Astra 的 54%；NVIDIA 称推理成本低 10–20 倍NVIDIA 与合作公司披露；公告未给完整样本量、置信区间或独立复测，不能视为对所有材料合成任务的比较
SciWorkBench（11 月 17 日 arXiv v1）依据同行评审论文和专家提出的情境，覆盖生物、化学、材料与物理；在 Claude Code 与 Codex 代理框架下统一执行和评分最佳代理平均分 57.38；作者总结三类常见失误：把科学知识转成具体步骤困难、多模态证据整合弱、自我纠错不足作者预印本结果；要结合论文中的任务权重、模型版本和工具条件理解，尚非独立基准复现
MolDraft（11 月 18 日 arXiv v1）300 组化学结构图—三维结构配对，覆盖天然产物、高价化合物和配位复合物；同一代理设置评估 9 个多模态模型，检查分子身份、立体化学与配体几何正确构建率在 25%–76% 之间；分子超过约 80 个原子后成功率明显下降；9 个模型都能解出的结构只有 29 个论文作者评测；文献中的金属配合物最难，结果尚待独立复现

AI4Chem 与 AI4Materials： LitmusBench 的价值在于把可用于后训练的数据与评价任务一同开放，涉及溶解度、药物代谢等分子性质；NVIDIA 报告的反应图抽取和量子点合成展示了从文献结构化到实验方案的两种路线。它们目前主要证明了特定数据和实验室配置下的收益。MolDraft 补上另一个实际瓶颈：从二维结构图生成可用三维构型，除了识别原子和键，还得满足立体化学与配位几何。

AI4Phys 与跨学科工作流： SciWorkBench 把化学、材料、物理、生物任务放进同一代理工作流测评，分数只有 57.38，说明单项知识题正确率不足以代表研究能力。它适合追踪计划、工具调用、证据整合和自我纠错；但跨领域平均分可能掩盖各学科差异，下一步应公开分领域结果、稳定基线、数据划分与专家评分一致性。

领导者与研究者本周值得关注的判断

  • OpenAI 把 Astra 的“AI 自我改进”能力列入 High 风险级别。 这是 OpenAI 自有 Preparedness Framework 下的判断，并非独立机构对“已实现自我改进”的确认。Epoch AI 的外部基准显示推理能力较前代提高，但开放式研究任务仍未见明显提升；UK AISI 的红队测试则显示，部分监测器在模型只需绕过行为监测时会失效。把三类证据并列看，比将一项风险标签读作能力里程碑更准确。
  • Satya Nadella 提出的企业 AI 衡量方式： 他把 Agent 365 Business Analytics 比作“AI 使用的 ERP 系统”，核心是把模型与代理的开支和可观察的业务结果关联起来。这个判断抓住企业部署的下一道门槛：模型调用量并不等于生产率，成本、质量、时延与人工复核都要进入同一套运营记录。(微软演讲全文（在新标签页打开）)
  • OVHcloud CEO Octave Klaba 对训练经济性的判断： 他称三年间训练成本下降了 20 倍，认为企业如今可以自行训练并运营模型，而非依赖少数实验室开放权重。这是公司负责人对行业成本曲线的估计；新闻稿未附其计算口径。Olala 的开放模型、公共超算训练和 CPU 推理速度提供了具体案例，但还需看模型质量、客户使用规模和总拥有成本。(OVHcloud 新闻稿（在新标签页打开）)

本周观察

竞争焦点同时落在能力、每项任务成本和可控性上。Astra 与 Neon 的独立综合指数只差 1 分，但不同指数任务耗时和费用差异明显；Qwen4-Max 与 Olala 则展示了稀疏混合专家（MoE）通过减少每次推理实际激活的参数来控制成本的不同规模路径。对科学 AI 来说，开放数据和专用后训练方案让研究团队更容易复现实验；新基准把评价单位从“答对一道题”推进到完成任务、构造分子和随证据修正结论。近期最值得跟进的是这些结果能否在公开任务、独立实验室和不同硬件上重复出现。
