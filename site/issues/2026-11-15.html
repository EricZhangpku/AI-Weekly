美国

  • Anthropic｜Claude Fable 5.2 与 Mythos 5.2 将能力和开放范围分层（11 月 9 日） 两款产品使用同一底层模型，Fable 保留网络安全与生物学防护，面向一般用户；Mythos 面向通过审查的网络安全和生命科学机构。Anthropic 称新模型比 5.1 最多快 30%，标准 API 价格为每百万输入/输出 token 8/40 美元；快速模式最多快 2.5 倍，价格翻倍。公司公布的高推理档成绩包括 FrontierCode 2.0 49.1%、FrontierSWE v2 69.9%、AutomationBench 51.4%、Terminal-Bench-Science 0.1 74.6%（Mythos 为 75.3%）、OSWorld 2.1 离线部分集 89.3%。这些是厂商报告，且表中基准的努力档位、任务集与工具链不完全一致。独立评测 Artificial Analysis 的 Index v5.0.1 给 Fable 5.2 的 max 档 65 分、high 档 62 分；max 档完成全套任务约需 44.5 分钟，单项综合评测成本约 5.74 美元。综合分领先不意味着每项任务都领先，推理成本和时间也高于较轻模型。(Anthropic 发布与方法说明（在新标签页打开），Artificial Analysis 独立评测（在新标签页打开）)
  • Google｜Gemini 4 Hydrogen 面向快速执行与代理工作流（11 月 12 日） Hydrogen 是 Carbon、Argon 之外的执行型模型，提供 low、medium、high、xhigh 四档推理强度，最长上下文 100 万 token，并进入 Gemini API、AI Studio、Gemini App、Search 和企业产品。Google 引用 Artificial Analysis 指数称，默认 high 档得 51 分，略高于 Argon 的 50；xhigh 档为 54。Artificial Analysis 独立页面显示，xhigh 档单项指数任务平均耗时 14.7 分钟、成本约 3.16 美元；价格为每百万输入/输出 token 1.50/7.50 美元。指数覆盖知识工作、编码、科学和通用任务，不能代替具体业务测试；“更快”也随推理档位变化。(Google 发布说明（在新标签页打开），Artificial Analysis（在新标签页打开）)
  • Meta｜Muse Ember 用低价小模型承接重复代理任务（11 月 9 日） Ember 是 Meta 使用 Muse Wonder Full 训练的轻量模型，提供 100 万 token 上下文并支持 Responses API；Meta API 标价每百万输入/输出 token 0.10/0.50 美元。Artificial Analysis 指数 max 档得 36 分，指数综合任务成本约 0.14 美元；独立评测的 OSWorld 2.1 部分得分 69.5%，使用部分得分规则。作为参照，指数中 Claude Haiku 5.5 max 也得 36 分，Meta 公布的同一指数任务成本约为其三分之一。不同模型所用代理框架和努力档位并非完全一致，适合比较价格与大致能力区间，不宜视为同条件胜负。(Meta 发布及测试口径（在新标签页打开），Artificial Analysis 独立评测（在新标签页打开）)
  • Google DeepMind｜AlphaProof Code 用多代理协作验证 Signal 代码（11 月 10 日） 研究团队先与安全专家确定要证明的性质，再让多个大语言模型代理拆分和执行 Lean 形式化证明，最终针对 Signal 参考实现证明了关键安全属性。DeepMind 称整个流程用时四周，并在隔离代码中重新引入两个真实旧漏洞，系统都能给出机器可检查的“不安全”证明。论文描述约 650 万行 Lean 证明代码和 2.6 万项可信规格/语义材料。它证明的是特定实现、选定性质及其形式化规格之间的一致性；系统没有自动决定所有安全性质，也不能证明 Signal 全系统绝无漏洞。(DeepMind 原文（在新标签页打开），技术论文（在新标签页打开）)
  • OpenAI｜ChatGPT Wallet 让代理代用户完成购物付款（11 月 13 日） 首批面向美国部分 Pro 用户，在 dots 产品中接入 American Express、Mastercard 与 Visa。用户每次购买仍需检查商品、金额和卡片，并通过生物识别等安全检查批准；支付网络向商家提供替代真实卡号的支付令牌。OpenAI 把“逐笔授权”作为首发边界，长期设想则包括用户预设额度、品类和期限后委托代理购买。这个产品把代理从搜集和比较商品推进到交易环节，实际覆盖仍受商户网站反自动化规则与风控系统影响。(OpenAI 发布说明（在新标签页打开）)
  • Nvidia｜Jensen Huang 辞任 CEO 和董事（11 月 12 日） 公司公告称董事会已接受 Huang 辞呈，Colette Kress 在寻找正式继任者期间出任临时 CEO，Harvey C. Jones 成为首位董事会主席。公告表示产品路线、客户承诺和运营不会中断。董事会向 SEC 的 8-K 文件确认，辞任于 11 月 11 日生效；有关调查和媒体报道涉及的指控仍应按报道归属，不应当作公司公告已确认的事实。(Nvidia 公告（在新标签页打开），SEC 文件（在新标签页打开）)

欧洲

  • Mistral｜Large 4 权重开放，并报告三周强化学习后的性能变化（11 月 5 日） 模型预览版在 10 月已推出，本周真正的新进展是改进版权重、模型卡与许可证开放。Mistral 报告 FrontierCode 2.0 得分 19.7%；Artificial Analysis Coding Agent Index 得 48%，称平均每项任务用 token 比 GLM-5.3 少 47%；Terminal-Bench 4.0 为 41%，较预览版提升 13 个百分点；防御性 Cyber Index 得 51%，恶意网络安全提示拒答率为 96.6%。这些成绩由 Mistral 在发布页报告，尽管部分测试来自 Artificial Analysis 或合作方，仍需结合各自任务、版本和复测方法看待。公司声称额外三周强化学习带来显著提升，并称“尚未看到饱和”；这属于厂商对训练进展的判断。权重使用修改版 MIT 许可，提供模型服务的商业平台另需许可；API 价为每百万输入/缓存输入/输出 token 0.70/0.07/2.10 美元。(Mistral 发布与数据（在新标签页打开），官方模型页与许可证链接（在新标签页打开）)
  • EUROPA｜欧洲公共超算展示近万亿参数 MoE 训练能力（11 月 12 日） 由 Domyn、Fraunhofer IAIS 与 Fraunhofer IIS 组成的 EUROPA 联盟在德国 JUPITER 超算上运行 951.9B 参数、每 token 激活 32.8B 参数的 MoE 配置，384 个路由专家中每 token 选 8 个，训练序列长度为 65,536。PyTorch/TorchTitan 工程报告称吞吐从每 GPU 每秒 90 token 提升到约 1,300 token；最终扩展配置为四组数据并行副本、共 1,536 张 GH200。关键改动包括优化器状态分片、把激活检查点卸载到 Grace CPU，以及把 FSDP 参数收集移到计算流。这个结果证明公共共享集群可以承载该规模的训练配置；文章没有证明一个面向用户的完整模型已完成预训练或发布。(PyTorch / EUROPA 技术报告（在新标签页打开）)

AI4S / STEM：新基准把视线移向研究过程

本周的科学 AI 线索集中在三种不同问题：化学模型是否能完成多步化学推理；分子表征能否跨数据集和混合物性质迁移；模型能否在实验室新证据陆续出现时更新判断。下面的分数来自论文作者评测，不能当作独立榜单。

研究任务与规模代表性结果证据状态
ChemInsight（11 月 9 日）203 道化学题组成 50 组多步任务，另有 50 道基础诊断题；提出“覆盖度”和“深度”两类分数10 个模型中，Gemini 3 Pro 最高：覆盖度 27.8%、深度 10.7%；人类专家覆盖度 36.3%arXiv v1 预印本；8 次采样取平均，部分自由回答由大模型评审
MatScope / MatEvoBench-20（11 月 9 日）200 项材料实验室任务，覆盖 10 类研究工作；测试无工具推理、文献辅助知识迁移，以及观察逐步披露时的预测修订作者报告 11 个模型/部署中，基础计算与不少物理解释较好；相近材料状态的细微比较、数值估计和有量化依据的决策仍弱arXiv v1 预印本；摘要没有给出可比的单一总分，适合读成任务设计与错误分析
Chem World + PACM（11 月 10 日）汇总 17 个公开数据集、80 万余个分子与化学体系实例、10 种性质；包含单分子和混合物PACM 的密度预测 R² 为 0.921、溶解度 0.891；作者的拆分实验发现来源留出和分子/组成留出会增加误差arXiv v1 预印本；数据单位与测量条件异质，作者也指出分组拆分仍不能保证未见分子和条件上的泛化
AI-Newton（11 月 4 日刊于 Physical Review Research）从 46 组经典力学实验数据中跨实验提取概念与一般规律；系统组合符号回归、变量控制和显式物理概念表示重新发现牛顿第二定律、能量守恒、万有引力等规律同行评审期刊论文；作者说明这是以模拟数据为主的受控概念验证，并非覆盖一般物理领域的自主发现系统

和 STEM benchmark 设计相关的观察： ChemInsight 的“深度分”奖励模型在同一组关联问题中连续答对，弥补只看单题正确率的不足；MatScope 则把材料状态、温度/条件变化和观察后修订纳入测评。这些设计更贴近研究判断，但仍需公开任务、明确评分者一致性，并用实验或专家盲评验证结论。Chem World 的价值在于把混合物纳入统一评测；读 R² 时要同时查看各性质的误差单位和数据划分，不能用一个宏平均掩盖溶解度、黏度、热力学性质之间的难度差异。

技术演进与评测观察

  • 模型开始按任务成本分层。 Fable 5.2 把更高推理能力放在长耗时、高 token 消耗的一档；Hydrogen 用四档推理深度控制速度和费用；Muse Ember 的综合能力低于旗舰，但独立指数任务约 0.14 美元。这些指标衡量的是不同评测套件，不是统一业务任务。更实用的采购问题是：轻模型能否承担重复步骤，把困难样本准确升级给旗舰模型。
  • 开放权重的竞争扩展到可部署性和后训练效率。 Mistral Large 4 本周开放权重后，披露的变化主要来自追加强化学习及更节省 token 的推理。EUROPA 则把优化重点放在训练阶段的内存、通信和主机卸载。一个解决模型下载后如何训练/运行/许可的问题，一个解决公共硬件怎样把稀疏大模型训练起来；参数总量不能单独代表模型质量。
  • 科学能力评测从“答对题”走向“保持推理链的可检查性”。 AlphaProof Code 把形式化规格和 Lean 证明作为可机器检查的产物；ChemInsight、MatScope 要求完成有关联的问题，并根据后续证据更新回答。不同领域的任务完全不同，但共同目标是让评测结果更容易定位模型是在哪一步失误。

研究者与行业负责人的重要判断

  • Anthropic 对 Mythos 的部署选择： 同一底层模型可以按防护等级分成广泛可用的 Fable 与受审查的 Mythos。这个做法表明模型发布边界开始与具体能力风险挂钩；目前访问资格仍由厂商项目管理，外部无法独立检验其安全筛选效果。(Anthropic 发布说明（在新标签页打开）)
  • DeepMind 研究团队的主张： 形式化验证或可被多代理流程扩展到真实软件实现，团队称这是首次以这种深度形式验证广泛部署的密码协议。最重要的技术主张不是“AI 证明了 Signal 安全”，而是对实际代码和明确列出的安全性质构造机器检查证明；这一边界决定了结果能证明什么。(AlphaProof Code 论文与公告（在新标签页打开）)
  • Mistral CEO Arthur Mensch 代表公司的判断： 发布页称追加强化学习带来的编码收益“尚未看到饱和”。这对模型训练效率很关键，但依据仍是 Mistral 对内部训练曲线和自选基准的描述；后续应看公开权重上的独立复测、训练成本和跨任务迁移。(Mistral 发布说明（在新标签页打开）)
  • 编辑判断： 本周值得追踪的变化，是模型能力开始同时按任务复杂度和风险分配：轻模型处理高频执行，旗舰模型接手长程推理，高风险模型通过验证计划受控开放。与此同时，科学评测也在把证据更新、过程验证和跨条件泛化纳入测试。两条趋势都把竞争焦点从单次答题分数移向“能力如何稳定地嵌入流程”。
